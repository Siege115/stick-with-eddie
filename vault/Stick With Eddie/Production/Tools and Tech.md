# Tools and Tech

Three.js 0.170, Playwright Chromium (headless WebGL), Node 22, ffmpeg, Python (numpy, scipy, soundfile, kokoro-onnx), the Kokoro TTS model (from GitHub releases), Claude Code agents. Optional connectors: vidIQ (analytics and research), ElevenLabs (voice; the audio host needs to be allowed in the network settings).
