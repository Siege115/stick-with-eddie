# Editing Resources #10 — Masking, Compositing & Advanced Overlays

> Combine visual layers, isolate subjects and create reveals using accessible tools.

**Scope:** 36 practical techniques and editorial concepts, grouped into 3 sections. Some are established film/postproduction terms; others are explicitly descriptive workflows rather than formal industry jargon.

**Application:** Roblox / Anime Breaker Shorts, faceless gaming guides, tutorials and challenge videos.

## Masking techniques

| Technique / method | Short explanation | Roblox or faceless-video use |
|---|---|---|
| **Linear mask** | Reveal an area along a straight edge | Split-screen comparison |
| **Radial mask** | Circular/elliptical visible region | Spotlight a secret item |
| **Feathered mask** | Soft boundary to blend layers | Seamless focus overlay |
| **Hard mask** | Crisp boundary | Comic-style split panel |
| **Animated mask** | Keyframe a mask across frames | Reveal a new world |
| **Subject cutout** | Separate a person/character from background | Put avatar in front of text |
| **Rotoscoping** | Draw/track changing subject edge frame by frame | Isolate a moving Roblox character |
| **Luma matte** | Use brightness as transparency | Stylized glow reveal |
| **Alpha matte** | Use transparency shape to reveal another layer | Show icon inside a graphic |
| **Track matte** | One layer controls where another appears | Animate title through a shape |
| **Inverted mask** | Reveal everything except masked region | Cut a portal hole |
| **Garbage matte** | Coarse mask removing unwanted regions | Clean green-screen edges |

## Compositing operations

| Technique / method | Short explanation | Roblox or faceless-video use |
|---|---|---|
| **Chroma key** | Remove a uniform background color | Place keyed effect over gameplay |
| **Screen blend** | Keep bright areas of a layer | Overlay sparks on dark footage |
| **Multiply blend** | Darken using overlaid layer values | Add moody texture without solid backdrop |
| **Additive glow** | Blend bright pixels into underlying image | Emphasize attacks carefully |
| **Opacity dissolve** | Crossfade two stacked layers | Smoothly compare states |
| **Picture-in-picture** | Show inset secondary footage | Compare build results |
| **Split screen** | Divide frame between views | Before/after, two routes |
| **Double exposure** | Combine semi-transparent scenes | Dramatic training montage |
| **Light wrap** | Add background-colored edge light to cutout | Integrate avatar into new scene |
| **Color matching** | Adjust insert to match base exposure/color | Prevent pasted assets looking disconnected |
| **Grain matching** | Match texture between layers | Blend stock effect with gameplay |
| **Shadow grounding** | Add subtle shadow under overlay/cutout | Stop subject appearing flat |

## Spatial composites and reveals

| Technique / method | Short explanation | Roblox or faceless-video use |
|---|---|---|
| **Foreground occlusion** | Let near objects hide part of overlay | Text appears behind player briefly |
| **Parallax layers** | Shift foreground faster than background | Fake depth from a still image |
| **Depth blur** | Blur background layer relative to subject | Direct focus to boss |
| **Portal reveal** | Mask a new environment through a ring | Transition into a raid |
| **Object wipe** | Moving foreground object covers next clip | Seamless doorway transition |
| **Clone effect** | Duplicate and offset subject layers | Show multiple builds side by side |
| **Afterimage** | Duplicate earlier subject positions with reduced opacity | Accentuate a dash |
| **Outline extraction** | Generate an edge border around isolated subject | Highlight hidden opponent |
| **Reflection composite** | Duplicate and flip into reflective surface | Stylized glossy title |
| **Replacement screen** | Composite footage into an in-scene display | Place boss stats on a sign |
| **Key spill cleanup** | Remove unwanted green edge tint | Improve chroma key appearance |
| **Occlusion correction** | Mask over portions that should be behind an object | Keep spatial logic believable |

## Ready-to-use example

Compare two sword builds: duplicate gameplay -> crop each to half-frame -> match scale and lighting -> title each side -> mask the winner reveal -> include the numerical difference.

## Avoid these mistakes

- Hard edges where feathering is needed
- Badly lit green-screen footage with green spill
- Effects hiding actual evidence
- Pretending a simple 2D zoom creates true 3D camera movement

## Final review checklist

- [ ] Do the foreground/background edges look plausible?
- [ ] Do layers match in color and scale?
- [ ] Does the effect clarify information?
- [ ] Can I recreate it on my editing device?

## Working notes

- In CapCut, exact feature names and availability can vary by platform and app version.
- A digital crop, blur or keyframe animation may simulate a movement but cannot reconstruct missing 3D camera perspective.
- For stats, codes and release-specific claims, verify the footage/game before publishing.
- Use original, licensed or otherwise permitted audio and visual assets.
