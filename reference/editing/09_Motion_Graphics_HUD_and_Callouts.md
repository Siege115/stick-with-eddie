# Editing Resources #09 — Motion Graphics, HUD & Information Callouts

> Design useful overlays, stats and animated labels without obscuring gameplay.

**Scope:** 36 practical techniques and editorial concepts, grouped into 3 sections. Some are established film/postproduction terms; others are explicitly descriptive workflows rather than formal industry jargon.

**Application:** Roblox / Anime Breaker Shorts, faceless gaming guides, tutorials and challenge videos.

## Five-second visual demo

Each labeled segment lasts roughly one second:

1. **TRACK LABEL**
2. **HP BAR**
3. **ARROW**
4. **COUNTER**
5. **PROGRESS**

## Information overlays

| Technique / method | Short explanation | Roblox or faceless-video use |
|---|---|---|
| **Lower third** | Information label near a lower screen edge | Identify a game world or boss |
| **Callout** | Label with a visual connection to a subject | Point to secret alley entrance |
| **Leader line** | Thin line connecting text to an object | Label distant hidden locations |
| **Arrow callout** | Arrow that directs the viewer toward an area | Guide the route through buildings |
| **Spotlight circle** | Ring placed around the important item | Show boss spawn or code menu |
| **Bounding box** | Rectangle framing a target | Mark a hidden chest |
| **Nameplate** | Compact identity label | Identify a boss before showing stats |
| **Stat card** | Group related measurements | HP, damage required and drops |
| **Comparison card** | Show two setups in the same visual hierarchy | Weak build vs stronger build |
| **Badge indicator** | Compact status icon with text | New, rare or update-specific |
| **Legend** | Explain the meaning of colors or marks | Clarify route map icons |
| **Disclaimer tag** | Small qualifier near a claim | 'Stats may change after update' |

## Animated UI elements

| Technique / method | Short explanation | Roblox or faceless-video use |
|---|---|---|
| **Progress bar** | Fill shape indicating completion | Show training or collection progress |
| **Health bar** | Fill representing remaining HP | Explain boss difficulty |
| **Damage counter** | Count up or tick to a value | Emphasize damage milestone |
| **Energy gauge** | Meter of available resource | Show build effectiveness |
| **Cooldown ring** | Circular countdown display | Demonstrate skill timing |
| **Timer badge** | Compact running clock | Speedrun or tower challenge |
| **Objective tracker** | A list that updates when objectives complete | Boss route steps |
| **Location breadcrumb** | Text showing where in the route viewer is | Devil City > second area |
| **Mini-map inset** | A small map area shown over footage | Show turn without stopping gameplay |
| **Split-stat graph** | Side-by-side meter comparison | Compare damage and energy upgrades |
| **Animated divider** | Short motion line separating sections | Divide location from reward information |
| **Text label tracking** | Label follows moving subject | Keep a boss identifier tied to its position |

## Motion design principles

| Technique / method | Short explanation | Roblox or faceless-video use |
|---|---|---|
| **Anchor positioning** | Keep overlay aligned to a chosen region or object | Label stays near the boss without drifting |
| **Easing curve** | Adjust the speed along a keyframe animation | Smoothly settle HUD panels |
| **Motion hierarchy** | Important elements animate more prominently | Make code readable before decoration |
| **Negative space** | Leave visually quiet space around copy | Keep gameplay action visible |
| **Consistent spacing** | Use repeatable padding and gaps | Make your stats recognizable |
| **Reusable templates** | Store design components for quick edits | Same boss stat card every update |
| **Entrance timing** | Animate overlay only when relevant | Show HP when health is discussed |
| **Exit timing** | Remove old overlays before new info | Avoid visual clutter |
| **Depth stacking** | Organize overlays foreground to background | Callouts above gameplay, atmosphere behind |
| **Color coding** | Map colors consistently to meaning | Orange for warnings, cyan for directions |
| **Motion reduction** | Use less movement during dense information | Keep code instructions readable |
| **Platform-safe positioning** | Reserve margins for captions and app UI | Prevent TikTok controls from covering stats |

## Ready-to-use example

Secret boss guide: location breadcrumb -> moving arrow at the turn -> tracked ring around spawn -> compact HP/damage card -> reward card with a brief progress animation.

## Avoid these mistakes

- Too much HUD obscuring the action
- Numbers with no labels or units
- Changing visual style in every Short
- Tracking labels that jitter

## Final review checklist

- [ ] Can the viewer see the actual gameplay?
- [ ] Is each number unambiguous?
- [ ] Are UI elements aligned and consistent?
- [ ] Do overlays appear only when relevant?

## Working notes

- In CapCut, exact feature names and availability can vary by platform and app version.
- A digital crop, blur or keyframe animation may simulate a movement but cannot reconstruct missing 3D camera perspective.
- For stats, codes and release-specific claims, verify the footage/game before publishing.
- Use original, licensed or otherwise permitted audio and visual assets.
